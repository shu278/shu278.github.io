## 一、与 ZoomEye 功能类似的搜索引擎

这类工具统称**网络空间测绘/网络空间搜索引擎**：24 小时不间断扫描全网开放端口与服务指纹（组件、版本、操作系统、证书等），让我们像搜网页一样搜**联网设备**。

| 搜索引擎 | 网址 | 特点 |
|---|---|---|
| Shodan | https://www.shodan.io | 美国，此类工具鼻祖，全球联网设备覆盖最广 |
| Censys | https://search.censys.io | 美国，学术项目出身，擅长证书与主机数据分析 |
| FOFA | https://fofa.info | 国内（白帽汇），国内资产覆盖好，语法灵活 |
| Quake 360 | https://quake.360.net | 国内（360），自带命令行工具 |
| Hunter 鹰图 | https://hunter.qianxin.com | 国内（奇安信），按查询价值积分制 |
| BinaryEdge | https://binaryedge.io | 侧重安全评分与情报订阅 |
| Netlas | https://app.netlas.io | 较新的测绘引擎 |

作为对比，我在 FOFA 中用 `server="Apache"` 实测，找到约 **2.05 亿**条结果：

## 二、ZoomEye 实操搜索

ZoomEye 语法：**用 `=` ，值要加英文双引号、多个条件用 `&&` 连接**（如 `app="apache" && ver="2.4"`）。常用字段：`app`（组件名）、`ver`（版本）、`port`（端口）、`service`（服务）、`os`（操作系统）、`country/city`（地理位置）、`device`（设备类型）、`domain`（域名）、`ip/cidr`（IP/网段）。

实测：

1. `app="apache" && ver="2.4"` —— 找到约 **25,363,612** 条结果（最近一年 4,448,882 条），首条即为运行 Apache httpd 2.4 的公网站点，验证了课件中"基于开源 CMS/组件的站点一旦爆出漏洞危害很大"的观点。

{% asset_img zoomeye1.png %}
*ZoomEye：app="apache" && ver="2.4" 实测 2500 万余条结果*

2. `port="22" && country="china"` —— 找到约 **19,305,160** 条结果（最近一年 5,327,367 条），可以看到大量开放 SSH 服务的主机（首条 145.40.124.149:22，Banner 为 SSH-2.0-OpenSSH_10.0p2），说明公网上暴露的服务远比想象的少管理得多。

{% asset_img zoomeye2.png %}
*ZoomEye：port="22" && country="china" 实测 1900 万余条结果*

3. `domain="guet.edu.cn"` —— 找到 **214** 条结果，能看到学校暴露在公网上的资产（如 zabbix.guet.edu.cn:443，标题"网络应用认证"，位于中国广西桂林），印证了"域名/子域名是站点资产梳理、安全排查核心环节"。

{% asset_img zoomeye3.png %}
*ZoomEye：domain="guet.edu.cn" 实测 214 条结果*

## 三、子域名收集（被动方式为主）

子域名是主站下挂接的其它主机。被动收集不触碰目标，目标无法觉察。

**方法 1：证书透明度日志 crt.sh**

HTTPS 证书签发会记录在公开的 CT 日志中，证书里常包含子域名清单。
查询地址：`https://crt.sh/?q=guet.edu.cn`（把域名换成目标即可；不要加 %25 通配符）。实测查到 `*.guet.edu.cn`、`guetpan.obs.cn-south-235.guet.edu.cn`、`mba.guet.edu.cn`、`idp.guet.edu.cn`、`lockapi.guet.edu.cn` 等子域名，颁发机构包括 DigiCert、Sectigo、Let's Encrypt、GlobalSign 等。

{% asset_img crtsh.png %}
*crt.sh 返回的 guet.edu.cn 证书/子域名列表*

**方法 2：在线查询站（已验证可用）**

`https://api.hackertarget.com/hostsearch/?q=guet.edu.cn` 直接返回"子域名,IP"表格，实测返回 40 余条记录（classroom、courses、idp、portal、wvpn、www 等，IP 多集中于 202.193.64.x 网段）。
同类：dnsdumpster.com（带可视化拓扑图）、virustotal.com 的 Domain → Relations。rapiddns.io 对 .cn/.edu.cn 域名有合规屏蔽，国内目标不适用。

{% asset_img hackertarget.png %}
*hackertarget 返回的子域名+IP 列表（40 余条）*

**方法 3：ZoomEye 与搜索引擎语法**

- ZoomEye：`domain="example.com"`，实测找到 4 条结果（www.example.com:443 等）：

{% asset_img zoomeye4.png %}
*ZoomEye：domain="example.com" 实测 4 条结果*

- Google/Bing：`site:*.example.com -site:www.example.com`

**方法 4：命令行工具**

```bash
# DNS 解析（Windows 自带）
nslookup example.com

# subfinder 纯被动收集（Kali/WSL）
subfinder -d example.com -passive

# Recon-NG（SOURCE 为目标域名）
recon-ng
marketplace install recon/domains-hosts/hackertarget
modules load recon/domains-hosts/hackertarget
options set SOURCE example.com
run
```

实测 `nslookup example.com`，解析到 `172.66.147.243`、`104.20.23.154`（Cloudflare）及 IPv6 地址：

## 四、小结

被动扫描的核心是"知己知彼"：通过 ZoomEye、Shodan 等测绘引擎与证书日志等公开渠道，在不接触目标的情况下即可勾勒出目标的资产轮廓（域名、子域名、开放服务、设备类型），这些信息既是安全排查的起点，也可能被攻击者利用进行社会工程学攻击——如课件中的摄像头案例，不少设备使用默认口令，被测绘引擎收录后存在被陌生人"围观"的风险。对防守方而言，主动梳理自己的公网资产、清理默认口令，同样是被动信息收集视角下的必修课。
